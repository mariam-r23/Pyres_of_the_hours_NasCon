# tools/

Level checks for the team. Owner: Mariam. Uses only the core API (`preload`, never `class_name`).

| command | what it does |
|---|---|
| `godot --headless -s tools/validate_levels.gd` | loads, validates and solves every level in `levels/data/`; prints id, valid, solvable, shortest, par. Exit 1 on any failure |
| `godot --headless -s tools/validate_levels.gd -- res://some/dir/` | same for another folder |
| `godot --headless -s tools/test_solver.gd` | checks the solver against the Python reference's answers |

**A level is not merged until `validate_levels` passes.**

`solver.gd` is a breadth-first search. `unsolvable` is a proof (the state space is finite); `limit` means a cap
(`max_states` 200000, `max_depth` 200) stopped it first. `expected_solutions.json` is generated by
`reference/python/dump_solutions.py`; regenerate it whenever a level or a rule changes.
